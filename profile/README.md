# Project AGi

> Building AIVA, an AI companion, and AuRoRA, an autonomous rover, through local AI, robotics, and exploration.

---

AGi is an open-source project exploring how AI companions and robotics can work together.

**AIVA** is an AI companion built around conversation, memory, and practical capabilities. **AuRoRA** is an autonomous rover designed to explore the natural world alongside her.

Built in beautiful British Columbia, Canada.
