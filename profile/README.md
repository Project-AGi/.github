# Project AGi — Amazing Grace infrastructure

AGi is the project behind **AIVA** and **AuRoRA**.

AIVA (AI Virtual Assistant) is an AI companion with a growing memory system and simple agentic capabilities.
AuRoRA (Autonomous Rover Robot Assistant) is an autonomous rover built to explore nature alongside her. Together, they bring local AI, robotics, and exploration into one project.

Built in Beautiful British Columbia, Canada.

[Explore the AGi repository](https://github.com/OppaAI/AGi)
